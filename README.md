# FMU Web Preview

Demo estática de carreira de futebol com dados fictícios.

O GitHub Pages deste repositório pode ser publicado usando a branch `gh-pages` na pasta `/ (root)` ou pelo workflow da `main` (Source: GitHub Actions).

Endereço previsto: https://thiagofernandes1987-create.github.io/FMU/

A aplicação é uma demonstração, não conecta FMU_Database, e o estado fica no navegador local.
